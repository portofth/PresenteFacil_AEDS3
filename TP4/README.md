# TP4 - CRUD de produtos em memória secundária

Este diretório contém a aplicação web do quarto trabalho, desenvolvida separadamente do software Java do PresenteFácil.

## Objetivo

A interface permite simular operações de CRUD de produtos em um ambiente web, representando acesso a arquivos em memória secundária.

## Arquivos principais

- `index.html`: interface principal da aplicação
- `img/`: imagens e recursos visuais
- `relatorioTP4.pdf`: relatório do trabalho

## Como abrir

Basta abrir o arquivo `index.html` em um navegador.
